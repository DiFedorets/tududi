## Интерфейс и поведение

Выбор диапазона находится в заголовке штатных «Предстоящих», без новой полосы и экрана. Нажатие на даты открывает компактное окно: начало/конец, «Со вчера», «С прошлой недели». «Эта неделя» возвращает понедельник–воскресенье текущей недели. В русской подписи диапазона убраны повторяющиеся месяц/год; переход года остаётся явным. На узком экране заголовок не обрезается, окно дат помещается в ширину экрана.

- «Со вчера»: вчера → семь дней вперёд от сегодня.
- «С прошлой недели»: понедельник предыдущей недели → семь дней вперёд от сегодня. На одной доске доступны прошлые задачи и будущие целевые дни.
- Свои даты: включительно, до 35 календарных дней. Пустые, некорректные, обратные и слишком длинные периоды отклоняются, прежний диапазон остаётся.
- Выбор хранится в URL (`range_start`, `range_end`); при reload сохраняется вместе с фильтрами/сортировкой. Без параметров исходный горизонт сегодня → +7 дней сохранён.
- Каждый день периода имеет явную дату, даже если задач нет. На большом экране столбцы можно прокручивать по горизонтали; проверен перенос через прокрутку. На телефоне сохраняется штатная вертикальная компоновка.
- Старые недели без дня остаются отдельными столбцами. Просмотр диапазона не назначает им произвольный день. При ручном переносе из/в такой столбец остаётся существующий выбор конкретной даты.

Смена диапазона — только чтение. Перенос целой карточки использует прежний PATCH задачи с CAS даты/времени, согласованием штатной даты, OnePlan, дневного плана и счётчика. Вторая дата задачи не добавлена. Быстрые комментарии и фоновое обновление сохранены.

## Реализация

Один серверный валидатор диапазона задаёт календарные дни и границы UTC в часовом поясе пользователя. Он используется в выборке задач, проектов и старых недель. Сервер возвращает `groupDates` (заголовок → YYYY-MM-DD), поэтому пустой дневной столбец — полноценная цель переноса, без угадывания даты по соседней карточке. API без новых параметров сохраняет прежнее поведение.

Материализованные повторяющиеся задачи прошлых дней видны, а виртуальные прошлые повторы не выдумываются. Перетаскивание повторов/привычек остаётся запрещённым, как в #9. Для виртуальных будущих повторов календарный день в выбранном диапазоне нормализуется в часовом поясе пользователя, чтобы отрицательный UTC offset не сдвигал его на вчера. Правила серий и привычек не менялись.

Изменения ограничены выборкой/группировкой и интерфейсом. Миграций и изменений схемы нет. Код адаптера One не менялся; новый диапазон не посылает ему отдельные записи.
