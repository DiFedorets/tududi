При изменении модели в том же PR обновлять этот каталог, снимок схемы и затронутый ADR. Проверять отдельно свежую установку и обновление существующей базы. В Git сохранять только код, схему и обезличенные результаты: без SQLite, выгрузок записей, токенов, конфигурации обмена и резервных копий.
