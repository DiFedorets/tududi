# Снимок структуры без данных

`sqlite.json` содержит типы, nullability, defaults, PK/FK, индексы и SQL таблиц/индексов/триггеров. `physical-erd.mmd` — полная редактируемая диаграмма связей, полученная из FK. Кардинальности на ней обзорные; уникальность составных ключей и точные ограничения смотрите в JSON.

Происхождение текущего снимка: **пустая документационная база из моделей исходной ревизии `69b2c423` + миграция строгого контекста `20261023000001`**, без пользователей. Это не снимок пилота и не доказательство успешного воспроизведения всех 172 миграций. Полный bootstrap сейчас прерывается на повторном индексе, см. [проверки](../verification.md). Схема, созданная моделями, может отличаться от последовательно обновлённой базы; до исправления bootstrap это ограничение сохраняется явно.

Воспроизведение с зависимостями проекта, в одноразовом контейнере без сети, без `.env` и без production volumes:

```sh
NODE_ENV=test DB_FILE=/scratch/documentation.sqlite node backend/scripts/build-documentation-schema.js
python scripts/schema-snapshot.py /scratch/documentation.sqlite docs/architecture/schema
python scripts/test-schema-snapshot.py
```

`/scratch/documentation.sqlite` должен быть новым путём. Builder отказывается перезаписывать существующий файл. Не используйте производственный путь/конфигурацию: builder создаёт таблицы, это не мигратор приложения. После генерации удаляется только одноразовая база; в Git добавляются JSON/Mermaid и исходники.

Экспортёр открывает SQLite `mode=ro` + `query_only`, читает только `sqlite_schema` и PRAGMA, не `SELECT *`, не строки таблиц, не значения sqlite_sequence или SequelizeMeta. Проверка безопасности создаёт синтетическую секретную строку и доказывает её отсутствие в результате и неизменность файла. Сам SQL схемы может содержать чувствительные литералы в нестандартной базе: поэтому публиковать результат разрешено только от пустой базы, созданной из проверенного кода. Генератор не является обезличивателем произвольной рабочей базы.
