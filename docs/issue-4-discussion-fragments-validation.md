## Поведение

- Необязательная дата обсуждения в строке метаданных. Указать/убрать можно через меню заметки, изменить — нажатием на дату. Дата создания не меняется, старым заметкам даты не приписываются. Календарная дата проверяется сервером; запись требует актуальной revision.
- Выделить текст → «Фрагмент» в существующей панели форматирования. Ссылка `/notes/<uid>?fragment=<uid>` копируется в буфер; тело заметки не меняется. При запрете буфера доступен адрес для ручного копирования.
- Ссылка открывает заметку, прокручивает к цитате и подсвечивает её. Переименование и правки полностью перед/после цитаты сохраняют привязку. Повторное копирование того же выделения в той же версии не создаёт новый якорь.
- При изменении/удалении цитаты показывается исходная цитата с предупреждением. Совпадающий текст в другом месте не становится новой целью. Сложная правка, охватывающая несколько мест, консервативно помечается как изменение: автоматического угадывания нет. Участники и внешние ссылки остаются обычным текстом.
- Больших панелей не добавлено. Прежний общий список связей остаётся свёрнутым под текстом.

## Хранение и безопасность

Миграция `20261023000002-note-discussion-fragments` добавляет nullable `notes.discussion_date` и `note_fragments` с FK на заметку (CASCADE). Исходная цитата и координаты версии неизменяемы; текущие координаты и хеш обновляются атомарно с CAS-обновлением текста. Переводы строк нормализуются только для координат, исходные байты текста сохраняются. При обходном изменении текста проверка хеша запрещает неверную подсветку. Создание якоря требует права редактирования; открытие — права чтения заметки. Публичного доступа через знание uid не появляется. Фрагмент ограничен 4000 UTF-16 единицами.
