# Штатное планирование и счётчик переносов — #1

Проверка 22.10.2026. Ветка `codex/native-planning-move-counter`, база — проверенная v1.9.6 (`1c396429`). После согласования результата пилот обновлён до кода `77709ad0`; итог развёртывания приведён в конце отчёта. Ниже сохранены результаты последовательных этапов стенда.

## Поведение

- Основные рабочие представления — штатные «Сегодня» и «Предстоящие».
- Из раскрытой и полной карточки убрана отдельная полоса One с планированием и переходом к общему плану.
- Дублирующие разделы недельного планирования убраны со страницы One; остаются «Ответы», очереди и статус обмена.
- Ненулевой счётчик переносов встроен в штатные действия карточки; нулевой скрыт. Долг ответа ведёт в штатное обсуждение. Защита закрытия задачи сохранена.
- Используется штатная дата задачи. Изменение календарного дня обновляет существующий контракт OnePlan и штатный DailyPlan в одной транзакции. Первое назначение — 0; другой день — +1; изменение времени в пределах дня не считается переносом. Очистка сохраняет историю счётчика.
- Новая обычная задача, созданная со штатной датой через REST/MCP, сразу получает совместимые данные обмена. Автоматические даты повторяющихся шаблонов этим начальным преобразованием не затрагиваются.
- Неизменённый локальный адаптер One продолжает читать/писать прежние поля planned/week/moves/revision. Его транзакционные изменения конкретного дня отражаются в штатной дате через модельные hooks.
- Существующие недели без дня сохранены без назначения понедельника как рабочего дня. Если такая неделя попадает в горизонт штатных «Предстоящих», она отображается группой «Неделя с … · без дня». Нового управления недельным полем в карточке нет.
