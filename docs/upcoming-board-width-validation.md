# Предстоящие: ширина доски и полные названия — 23.10.2026

Ветка `codex/upcoming-board-width` от `0f72d085`. Исправление только на стенде 18516; пилот и One не менялись.

Причина: ограничение max-w-7xl на странице (при текущем масштабе внутренний board 1152 px) и line-clamp-3 у названий карточек. При 3066 px viewport содержимое шириной 1742 px обрезалось/прокручивалось в узкой центральной области.

Проверки: production/TypeScript build, ESLint, 36 frontend-тестов TaskRow/UpcomingBoard/UpcomingRangePicker PASS. В Chromium на 3066×1296 board стал 2659 px, все семь столбцов по 361 px помещаются без горизонтального обрезания. Полные названия без clamp подтверждены по computed style/геометрии. На 1440 px горизонтальная прокрутка при необходимости сохраняется; на 390 px нет переполнения страницы. Обычный список остаётся max-w-7xl. Ошибок страницы нет. В браузерной проверке разрешены только GET, бизнес-записей не делали.
