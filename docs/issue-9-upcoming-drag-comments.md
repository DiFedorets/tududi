# #9 — перетаскивание и быстрые комментарии в «Предстоящих»

Статус: реализация в отдельной ветке `codex/upcoming-drag-comments`, подготовлен стенд для проверки владельцем. Пилот и рабочий обмен One не изменялись. База ветки — `ac86c125`, то есть версия после #3.

## Что изменено

- Карточка переносится целиком, без ручки, как на канбан-доске. Захват отделён от обычного клика порогом движения; кнопки, ссылки и редактор комментария не запускают перенос. Для сенсорного ввода используются штатные датчики с удержанием; с клавиатуры доступен Alt + стрелка влево/вправо на фокусированной карточке.
- Целевой столбец подсвечивается. Столбцы и их подписи остаются штатными: конкретный день определяется по сериализованной дате задач, без разбора локализованного заголовка. Столбец без конкретного дня требует явного выбора даты, а не назначает её автоматически.
- Сохраняется единственная штатная дата и, если оно было задано, время. Существующий механизм согласует OnePlan, DailyPlan и счётчик переносов. Перенос обратно через «Undo» — обратное изменение даты через тот же механизм учёта, а не ручная правка счётчика.
- Проверка исходных даты и времени выполняется в транзакции. Устаревшая запись возвращает 409 и не меняет планы. Защита совместима с прежними клиентами: дополнительные условия передают новые клиенты, контракт рабочего адаптера One не менялся.
- Иконка комментария доступна и при нулевом количестве. Она раскрывает внутри карточки штатный CommentComposer. Есть «Отправить», «Отмена», Ctrl/Cmd+Enter и Escape. Ошибка сохраняет текст; повторная отправка во время запроса блокируется. Отмена скрывает форму, сохраняя черновик при повторном открытии этой карточки. Открытый черновик другой карточки не сбрасывается обновлением списка после переноса.
- Автор, упоминания в тексте, история и правила человеческого/агентского ответа используют штатный API. Счётчик комментариев обновляется; последний отправленный текст показывается в карточке.
- Виртуальные повторы, повторяющиеся серии и привычки не переносятся этим жестом: дату нужно изменить в полной карточке. Это предотвращает неявный сдвиг всей серии; ограничение указано в доступном имени элемента. Штатный канбан и остальные виды не переделывались.
